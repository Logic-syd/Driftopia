# Phase 3A 经济平衡报告

状态：**已运行的配置驱动策略模型；长期经济平衡仍有明显风险。**

本报告只覆盖实际交付的 Phase 3A：原有打捞、八类建筑、生产、订单、三类船、五片海域和十五个探索事件。居民、建筑专精、新多级生产链、统一天气、公共灯塔、清理活动尚未实现；没有将未来奖励或维护费用加入结果。这里的数值是模型执行结果，不是玩家遥测、API 压测、日活预测或留存承诺。

## 策略与边界

每天在模拟时间 00:00、12:00 登录两次，休闲每次 10 分钟、普通每次 22.5 分钟、活跃每次 60 分钟。所有检查点都是注册后的**自然经过时间**；第 N 天截取在下一天登录前。休闲玩家前 30 分钟只有 10 分钟在线，绝不把全天按在线计算。

每 5 秒最多一个成功的玩家意图；每次决策前读取一次状态并按实际规则结算。策略优先保留第一座仓库的材料，完成可交订单、投资码头/船、推进海域；为维修保留木材，为后续造船保留合金。自动生产只在每次登录最后 30 秒依次开启，下一次登录依次关闭，之后按需求手动安排生产。这是一种知道玩法的确定性策略，不模拟首次游玩的学习成本或 UI 寻路时间。

关键边界均来自当前代码：

- 注册资源、100 金币、9 块地板；初始六个漂流物是 `SALVAGE` 每项各一个。后续每 10 秒生成，最多六个、180 秒过期，按种子均匀抽取。选择漂流物按出现顺序，不偷看隐藏掉落来挑高价值奖励。
- 仓库总容量为 80 + 每级仓库 80；该策略每种建筑最多一座，仓库最多三级，策略容量上界 320；这不是游戏的全系统容量上限。真实游戏可以建设多座仓库和扩张地板，本策略没有模拟。八类建筑可以放入初始九格，所以本策略没有虚构地板扩张支出。丢弃资源是明确记录的消耗项。
- 手动每建筑最多 3 份、自动最多 30 份，投入在排队时预付；实际 `productionSeconds` 根据建筑等级计算。离线只让已排任务到时，**不在过去补排新任务**。满仓产出保留在任务中。
- 自动结算顺序固定为建造顺序，服务端实际使用 UUID 顺序；这会影响满仓时哪项产物先入库，属于已知模型简化。
- 玩家订单仅三槽、按最早发放到期时间/等级/code 排序补入，30 分钟到期；初始水单优先呈现。可先交其他可支付订单，模型并未强制先交水单。新增合金研究订单会占用真实槽位，不能任意选择全部模板成交。
- 船成本、升级、维修、物资、耗时、路线前置任务与等级直接引用配置/纯规则。探索调用实际 `createVoyagePlan`，派遣时一次生成隐藏结果，选择不重抽。休闲/普通/活跃分别只接受显示成功率至少 100%/80%/60% 的额外事件选项；不足则安全返航。选择策略不读取隐藏的成功结果。
- 船停泊、等待事件决定和未卸货时不能再次派遣。离线不会替玩家选择事件或领取奖励。已解锁海域还要满足船等级才能进入。
- 使用仓库中的真实资源支付；所有账本逐项满足“初始 + 收入 − 支出 = 当前库存/金币”。生产中的已付原料不再属于库存，尚未领取产物也不算库存。
- 玩家市场假设 **零成交**。不存在可从现有代码推导的真实需求曲线，不能捏造收入、价格或成交率。管理员配方覆盖、网络延迟、失败请求时间成本、居民维护和未来活动均不加入模型。

旧 `scripts/economy.ts` 在每个 tick 遍历所有订单模板直接成交，并未模拟三槽与真实轮转，也没有船只及真实每日会话预算；其旧结果不能作为本阶段平衡证据。为保留历史工作，旧脚本未删除，新报告使用新模型。

存在明确的长期通胀：12–48 秒的演示生产节奏、淡水/鱼零投入、委托可循环补入且无周期预算，持续在线可以持续发行金币和经验。航海补给/维修创造了消耗，但本模型中仅对冲一小部分委托收入。这里没有声称发现“零时间复制资源”漏洞；有生产时长的正常循环本身就会无限期增加货币供应。数据库幂等与资产守恒无法替代经济平衡。

研究订单具有实际资源出口，但收益也偏高：安全探索残骸区两次至少得到两合金，基础派遣费 8 金币，合金研究单收入 75，差额 67 **尚未扣掉金属、补给、修理、造船投入与操作机会成本**。种子研究单的三种子通常需两至三次无额外奖励的珊瑚航程，基础派遣费 12–18、订单收入 90；遗物单一次失落航道保底遗物，基础派遣费 14、订单收入 140，仍另付木板/淡水。以上是配置算术，不是市场净利润。

## 成长、瓶颈与船只机会成本

基准种子首次派遣均在第 300 秒，首个海湾奖励在第 350 秒。普通/活跃的首个研究订单在第 915 秒；休闲玩家因离线事件等待推迟到第 86680 秒。新玩家开局零建筑/零船，七日得到实际生产与船队成长：

| ---- | --------------------------------------------- | ---------------------------- | ---------------------------------- |
| 休闲 | 3 / 2 / 2 / 2 / 2 / 1                         | 3 / 2 / 1                    | 173190 秒（48.11 小时）            |
| 普通 | 3 / 2 / 2 / 2 / 2 / 1                         | 3 / 2 / 1                    | 173265 秒（48.13 小时）            |
| 活跃 | 3 / 2 / 2 / 2 / 3 / 2                         | 3 / 3 / 2                    | 2735 秒（0.76 小时）               |

当前七日差异主要是数量和库存管理，**不能声称已有七日内容深度**。1800 XP 已是第七级，普通/活跃玩家在第一天即满级；全五区可很快解锁。路线前置保证顺序，时间与材料并未形成长期阶段。

发现一个需要明确改进的船型平衡问题：将每区各掉落最大值与该区最大事件 bonus 相加，海湾/残骸/珊瑚/风暴/失落分别为 **14/11/15/18/15 单位**。全部不超过一级小艇 18 货舱，因此当前配置下更大货舱不增加单航程可带回量。回收船仍提供更高抗性和额外并行船位，帆船更快，但货舱专精没有兑现。小艇升三级即可满足全部海域船级条件，昂贵船型不是硬性进度门槛。应调整“单次可打捞量/可选目标”或船型用途，再复跑收益；不应仅为强推新船而强制淘汰已有小艇。

当前链条没有在模型中陷入不可恢复的资源依赖环：小艇只需原始木材/塑料；残骸区可用一级小艇产出合金；木工先产木板可造回收站，回收站产零件支持后续船升级；补给来自基础建筑。15 次七日运行均到达全部账户海域解锁。然而，这不是对所有玩家策略的死锁证明。提前把木材花光、满仓零投入产物、未为订单保留材料都会显著拖慢发展；明确的丢弃/仓储引导和资源预留提示仍然必要。

## 市场价值与费用

本研究不建立 NPC 无限收购或虚构玩家市场价格，因此交易收入为零。实际市场 fee 为 `ceil(quantity * price * 5%)`，买家支付全款，卖家收到总额减手续费；资金在玩家间转移，手续费是全服货币消耗。

小额交易存在取整效应：总价 1 金币手续费 1（有效税率 100%）；总价 20 金币手续费 1（5%）；总价 21 金币手续费 2（约 9.52%）。合并数量能缓解小额取整，但实际供需、玩家愿付价格、手续费收入必须从真实交易中测量。对每项材料的机会价值应同时考虑订单的保留价值、造船用途和生产时间，不能把本模型订单回款当作市场价格。
