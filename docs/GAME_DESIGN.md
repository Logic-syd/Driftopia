# 游戏设计 · 第一版

## 体验

明亮而安静的海风群岛。海洋不是灾难背景，而是资源来源和连接玩家的空间。美术由 Phaser Graphics 原创绘制，使用蓝绿色海面、暖木色木筏、奶油色卡片和鼠尾草绿按钮。建筑图标使用系统 emoji；没有复制任何参考游戏素材或剧情。

## 纵向循环

点击漂流物 → 获得材料 → 建净水器 → 入队生产 → 收取淡水 → 交付订单 → 获得金币/经验 → 建造码头 → 交易。

新玩家拥有 3×3 木筏、100 金币、18 木材、12 塑料、4 金属、2 海藻。新手引导基于真实存档状态计算，不额外发放可重复奖励。

## 操作

- 点击漂流木、瓶子、金属或宝箱打捞；快捷打捞适合触摸/键盘操作。
- 建造菜单选择设施，再点击空地；绿色区域表示可放置。坐标列表提供可访问的替代操作。
- 点击建筑进入生产/升级/移动面板。
- 拖动平移，滚轮、双指或按钮缩放；中心按钮复位。
- 底栏进入仓库、委托、市场、好友、排行；头像进入资料。

## 当前界限

没有战斗、天气数值效果、居民需求或探索系统。居民小屋提供繁荣度；海上花园只生产海藻。场景船只和远方岛屿是装饰，不冒充可探索内容。好友访问是只读缩略岛屿。手动生产最多三批；可开启自动续产，最多预排 30 批并预扣材料。离线只完成既有任务，回岛后收取并续排。满仓/缺材料时暂停，恢复条件满足后继续。
